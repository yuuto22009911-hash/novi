# Novi UI

One core, several aesthetics. `@novi-ui/core` owns behaviour, accessibility and the slot
contracts; a theme package owns structure and style. Switching themes changes how the DOM is
assembled, not just colours. Version 0.5.0, 29 slot contracts.

Full reference: [references/components.md](references/components.md) (props, slots, examples).
Live docs (Japanese): https://novi-42r.pages.dev — English entry: https://novi-42r.pages.dev/en/

## Install

**Requires React 19 and Tailwind CSS v4.** Theme CSS ships token definitions only; the
component classes are generated by the consuming project's Tailwind through `@source`.
**Without the `@source` line everything renders unstyled.** Check it first when a Novi
component "has no styles".

```bash
pnpm add @novi-ui/core @novi-ui/raster react-aria-components
```

```css
/* app/globals.css */
@import "tailwindcss";
@import "@novi-ui/core/base.css";
@import "@novi-ui/raster/raster.css";
/* path is relative to this CSS file (src/app/globals.css → ../../node_modules/...) */
@source "../node_modules/@novi-ui/raster/dist";
```

Import components from the theme package, never from core:

```tsx
import { Button, Input } from '@novi-ui/raster'
```

## Theme, scheme and colourway

All three are attributes on `<html>`. No provider exists — do not wrap the tree.

```html
<html data-novi-theme="raster" data-novi-scheme="dark" data-novi-color="brick">
```

- `data-novi-theme`: omit when a single theme's `<theme>.css` is imported. Use `<theme>.scoped.css` to run several themes on one page
- `data-novi-scheme`: `light` | `dark`. Omit to follow the OS
- `data-novi-color`: one of the theme's colourways. Names differ per theme; an unknown name falls back to the default

- `@novi-ui/raster` (Raster) — minimal / Swiss grid. Modal floats in the centre; close is ✕ at the top right
- `@novi-ui/tactile` (Tactile) — touch-first, larger surfaces. Modal is a bottom sheet; close is full-width in the footer
- `@novi-ui/flatlay` (Flatlay) — no z-axis, paper and ruled lines. Modal replaces the page; Select / ComboBox / DatePicker expand in flow and push content down

Colourways (`data-novi-color`):

- **Raster** (default `ink`): `ink` / `prussian` / `forest` / `olive` / `ochre` / `brick` / `bordeaux` / `graphite`
- **Tactile** (default `indigo`): `indigo` / `peacock` / `sage` / `saffron` / `madder` / `cochineal` / `mauve` / `greige`
- **Flatlay** (default `fieldbook`): `fieldbook` / `blueprint` / `carbon` / `ribbon` / `eraser` / `manila` / `legalpad` / `pencil`

`success` / `warning` / `danger` are unaffected by the colourway.

## Rules (these differ from other libraries)

- **`isDisabled`, not `disabled`. `onPress`, not `onClick`. `isSelected`, not `checked`** (React Aria conventions)
- **Every component emits `data-slot="<name>"`.** Target these to override styles; do not reach into internal class names
- variant is one of `solid | outline | soft | ghost | plain`; size is `sm | md | lg`; color is `default | primary | secondary | success | warning | danger`; radius is `none | sm | md | lg | full`
- Colours only through `--novi-color-*` custom properties. Never write literal colour values
- **Spacing is a token too, not `p-4` / `gap-4`.** Inside a surface: `--novi-pad-surface-x` / `--novi-pad-surface-y`. Horizontal padding of a control: `--novi-pad-control-x-{sm,md,lg}`. Between elements: `--novi-gap-{inline,stack,section}`
- Headings: `--novi-font-heading` / `--novi-tracking-tight` / `--novi-leading-heading`. Body: `--novi-leading-body`. Figures: `--novi-font-numeric`
- Extend styles with `tv({ extend: <name>Styles, slots: { ... } })` — `base` has no effect on a slot definition. Override a variant's classes with `classNames={{ <slot>: '...' }}`
- Anything not in the component table below is **not implemented**. Do not substitute something similar; use react-aria-components directly and say so (it ships no styles)

## Pitfalls worth checking before you finish

- **DatePicker values are `DateValue`** (`@internationalized/date` `CalendarDate`), never strings or `Date`. Build them with `parseDate('2026-09-05')` or `today(getLocalTimeZone())`
- **NumberField reports an empty field as `null`**, never `NaN`
- **ComboBox cannot be opened from props** (`isOpen` does not exist); use `menuTrigger="focus"` if it must open on focus
- **Table needs `aria-label`** and at least one `TableColumn isRowHeader`. Wrap it in `overflow-x-auto` — the table scrolls, the page must not
- **Pagination**: `page` is 1-based; `onChange` receives the new page number
- IME: Enter and arrow keys during Japanese composition never reach handlers or the list — do not add your own guards
- Modal / Select / Toast structure differs per theme by design (Flatlay's Modal is a full-page takeover). Do not "fix" it with position overrides

## Classes you must not write

CI checks these mechanically per theme; a violation fails the build.

### Raster (`@novi-ui/raster`)

- `shadow-*（shadow-none とトークン shadow-[var(--novi-shadow-*)] は可）` — 影はトークン経由で、浮いている層だけに使う。面は境界線と背景色の差で表す
- `rounded-md / lg / xl / 2xl / 3xl と任意値の角丸` — 角丸はトークン経由。Raster は sm=6 / md=8 / lg=12px の3段
- `border-2 以上` — 境界線は 1px のみ。面の分割は線の太さでなく余白で行う
- `scale-* / scale-x-* / scale-y-*` — 動きで飾らない。モーションは opacity と translate のみ
- `rotate-* / animate-spin` — 同上。回転は Spinner のみ例外（ADR-R2）
- `リテラルの色値（#fff / rgb() / hsl() / oklch()）` — 色は必ず --novi-color-* を経由する。リテラル値を書かない
- `duration-*（--novi-duration-* の任意値を除く）` — モーションの時間はトークン経由にする
- `8px 以上の生の余白ユーティリティ（p/px/py/pt/pb/pl/pr/gap-2 以上）` — 余白はトークン経由（--novi-pad-* / --novi-gap-*）。余白がテーマの所有物でないと、各コンポーネントが各自の判断で数値を書き、3モデルが同じ密度に潰れる。8px 未満の微小インセットは部品の位置合わせなので生値を許す

### Tactile (`@novi-ui/tactile`)

- `トークンを経由しない角丸（rounded-sm / rounded-full / rounded-t-xl など）` — 角丸はトークン経由。Tactile は sm=8 / md=14 / lg=20px で、none 以外は 8px 以上
- `トークン外の影（shadow-md / shadow-[0_1px…] など）` — 影はトークン経由。値は α ≤ 0.24 に縛られている
- `border-2 以上` — 境界線は補助。使う場合も 1px のみ。面の分割は影と背景色差で行う
- `押下状態以外の scale-*` — 装飾目的の scale は使わない。押下フィードバック（data-[pressed]:scale-*）のみ許可
- `rotate-* / animate-spin` — 回転は Spinner と Accordion のシェブロンのみ例外（ADR-T4）
- `リテラルの色値（#fff / rgb() / hsl() / oklch()）` — 色は必ず --novi-color-* を経由する。リテラル値を書かない
- `8px 以上の生の余白ユーティリティ（p/px/py/pt/pb/pl/pr/gap-2 以上）` — 余白はトークン経由（--novi-pad-* / --novi-gap-*）。余白がテーマの所有物でないと、各コンポーネントが自分の判断で数値を書き、3モデルが同じ密度に潰れる。8px 未満の微小インセット（アイコンの位置合わせ）だけ生値を許す
- `duration-*（--novi-duration-* の任意値を除く）` — モーションの時間はトークン経由にする

### Flatlay (`@novi-ui/flatlay`)

- `z-index の指定（z-10 / z-[999] / zIndex）` — Flatlay は z 軸を持たない。重なりの順序は DOM 順だけで表す（例外なし・FR-02）
- `fixed / absolute` — 浮く面を作らない。例外は modal.styles.ts（テイクオーバー）と tooltip.styles.ts の2つだけ（FR-03）
- `sticky` — 滞留も重なり。スクロール中にコンテンツへ被る時点で z 軸の語彙になる（ADR-F4）
- `トークン外の影（shadow-md / shadow-[0_1px…] など）` — 影は嘘（浮く層が存在しない）。トークンは全段 0 0 #0000 で、書いても何も出ない
- `高さ・スライドのアニメーション` — 展開・格納は即時。押し下げに transition を付けると後続が滑り続けて読めなくなる（FR-12 / ADR-F1）
- `scale-* / translate-* / rotate-* / animate-spin` — 押下は反転（スタンプ）で示す。動きで飾らない。例外は spinner.styles.ts のみ（FR-11）
- `トークンを経由しない角丸（rounded-sm / rounded-full / rounded-t-xl など）` — 角丸はトークン経由。Flatlay は書類の直角で sm=md=2 / lg=4px
- `リテラルの色値（#fff / rgb() / hsl() / oklch()）` — 色は必ず --novi-color-* を経由する。リテラル値を書かない
- `duration-*（--novi-duration-* の任意値を除く）` — モーションの時間はトークン経由にする（Flatlay は 100ms の1本しかない）
- `8px 以上の生の余白ユーティリティ（p/px/py/pt/pb/pl/pr/gap-2 以上）` — 余白はトークン経由（--novi-pad-* / --novi-gap-*）。生値で書くと3モデルが同じ密度に潰れ、「余白がテーマの所有物」でなくなる。8px 未満の微小インセットだけが例外（字やアイコンの当たり合わせ）
